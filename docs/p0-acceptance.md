## 可重复执行的接口验收

在项目根目录执行只读检查：

```powershell
python scripts/acceptance_cloudflare.py --output artifacts/cloudflare-acceptance-latest.json
```

包含真实对话的检查需要显式使用 `--chat`：

```powershell
python scripts/acceptance_cloudflare.py --chat --output artifacts/cloudflare-acceptance-chat.json
```

`--chat` 每次发送两条带唯一标记的消息：一条验证 SSE 回执、结束标记和查询结果一致；另一条在收到任务编号后关闭流连接，查询同一个任务直到完成，不重新 POST。它可能调用真实模型并留下事件记录；`remember=false` 不是完全无持久化。若响应超时或结果不明确，应先按报告中的任务编号查询，不重复发送。脚本在发送前记录尝试标记，在获得任务编号后立即保存，便于中断后核对。

应用令牌只发送给固定本机地址 `127.0.0.1:8000`，公网检查使用独立匿名客户端，不跟随登录重定向。报告不保存令牌、Cookie、登录 URL 参数、记忆正文或导出正文。导出仅在内存中检查 ZIP 条目与 CRC，不解压到笔记库。所有结果都附本次读取时间；数据库持续变化，条目数不是固定验收值。

## 公网浏览器验收顺序

以下必须在正式域名记录实际结果，不能用源站接口或模拟测试替代：

1. **登录与加载**：进入 Access 登录流程，登录后显示星图且无接口错误。记录首次加载结果和时间。
2. **节点与来源**：选节点、打开来源事件；检查缺失记录有明确提示，未把引用当成事实证明。
3. **局部关系**：固定中心，展开到两层，选择间接节点；检查路径、关系详情、方向与具体名称筛选一致，重置恢复范围。
4. **刷新恢复**：调整缩放、平移、中心和筛选，再点页内“刷新记忆”；仍存在的视图状态保留，补充邻居读取重置有提示。浏览器整页刷新不承诺恢复状态。
5. **流式对话**：发送唯一标记测试消息，收到成功回执和正文；不把状态元数据当回复。
6. **断线恢复**：在隔离的验收页面中断开连接，再恢复；原请求只查询结果，不自动重新提交。记录任务编号和结果。
7. **登录失效**：在独立验收会话中验证 Access 会话失效后有重新登录提示，输入不丢失，POST 不自动重发。不要为了验收修改 Access 安全策略。
8. **导出**：点击导出得到有效 ZIP；登录页或错误页不得保存成 ZIP。
9. **手机实机**：以上关键操作在真实手机浏览器复验，记录设备和浏览器。390×844 模拟视口不替代实机结果。

本轮浏览器控制获取正式标签页超时，重新查询浏览器清单也连接失败；未取得页面状态。**这证明控制链路不可用，不能据此断定网页、Tunnel 或模型服务故障。** 公网匿名访问的登录跳转正常，已登录页面是否正常仍未知。

### 2026-10-01：修正实时数据拦截的误判

9 月 27 日的关键词拦截会把“解释指数函数”“今天帮我读文件”等普通请求误判为实时查询。本轮改为对完整的简短查询匹配：明确的行情、天气、新闻查询在没有网络工具时仍直接提示能力限制；解释、历史问题、本地工作和用户贴出的数据不再因为包含关键词而被提前拦截。未匹配的复杂查询仍通过模型及既有来源、时间戳和能力提示规则处理。这是保守的快捷回复范围，不是完整的意图分类或事实验证器。

快捷回复支持前置的中文／英文输出要求；其他语言请求交给模型处理。回执记录实际可用工具数量和传入上下文数量，`tool_rounds=0` 表示没有执行工具。修复原测试中 `return` 后无法执行的提示词断言，并增加本地读取工具确实能执行、用户数据能送达模型以及同步／流式路径的回归。

首次重启后的真实源站“解释指数函数”已进入模型，但任务因 `invalid_response_contract` 失败；独立模型调用复现了正文在 `eva_response` 外、主张使用不同措辞的问题。保留该失败任务编号，没有自动重发。随后明确 JSON 转义、全部正文放进 `message`、主张必须逐字匹配的提示，并增加最多一次格式修复调用。只有格式／主张文字对应错误可以触发；执行失败、无证据事实、虚构证据、缺少观测时间或未知主张高置信度不触发。修复不能执行工具，仍经过同一审查；普通文本、再次错误或模型调用失败不能绕过原结构化拒绝。流式路径只提交最终候选，不拼接两份回答。此机制可能增加一次模型调用，不保证模型一定修复成功。

# PERF-01 中间观测

2026-10-01。状态：开发中，未通过最终性能验收。测量后用户新增全界面统一主题范围，本批先交付 THEME-01；原性能与跨浏览器门槛保留。

测量设备为 HUAWEI CREM-WXX9、Ryzen 5 5600H、约 16GB RAM、Windows 11 build 26200；Codex 内置浏览器 Chromium 154，1015×924 测试窗口。使用独立开发探针 `scripts/cube_ui_probe.js`，不加载到产品模板或便携品牌包。测量对象是当时已加载的品牌工作区，源码指纹见 `artifacts/brand-studio/perf01/sources-before-theme.json`；本次主题变更后的性能尚未重测。

rAF 只测回调间隔，不等于实际绘制帧率。`document.visibilityState=visible` 也不能证明物理前台或未受宿主节流，因此不据此宣称 60 FPS，不将三阶记录作为应用前台性能故障或通过证据。PNG／ZIP 耗时为页面生成路径，不包含原生文件保存。

二阶隐藏品牌工作区后，块位置／朝向与动画时间保持，返回后继续；用户暂停不被工作区返回解除。这是工作区隐藏证据，未完成实际浏览器页面隐藏的原生生命周期测试。

连接的 DOM／window／document 监听器观测为探针前 67、探针安装后 69，后续观察保持 69；新增两项由探针自身引入。计数不涵盖已断开的 DOM、所有 MediaQueryList 或宿主内部监听器。采样 DOM 二阶 306–307，三阶 432–433。`performance.memory` 为粗粒度堆观测，不足以证明无泄漏。

探针采样最多 256 条；三阶最后一条在约 639.586 秒，后段内存／DOM 没有定时样本。停止后读取的 `preview` 是读取时的实时状态，循环数应以带时间戳的样本为准，不能用迟读数值冒充测量终点。补测与前段之间未计入的间隙也不拼成完整逐帧时间线。三阶计划中的三次导出和隐藏组合未全部完成。

以上限制属于原始观测，不修改或补造旧记录。后续探针修复与当前主题版本的新证据如下。

## 后续：探针修复和当前主题版本三阶验证

探针快照格式 2 按计划时长调整采样间隔，最多 256 条并始终保留第一条与终点；停止时排空待交付长任务并冻结状态与动作日志。稍后读取或调用者修改返回对象不会改变终点证据。提前停止会记录尚未完成的导出；PNG／ZIP 各自记录，重叠时不能确定归属的光栅样本明确标为 `rastersAmbiguous`，不假定它属于某个任务。五项探针回归通过，包括模拟十五分钟窗口、零时刻开始、冻结状态、提前停止／清理及并行导出。

# EVA × Obsidian 记忆图谱（OBS-01）

EVA 首页现在显示来自记忆数据库的三维星系图。原对话页移至 `/chat`，旧记忆列表移至 `/memory/list`，`/memory` 与首页显示同一图谱。

## 使用

完整服务继续按项目原方式启动。图谱支持搜索、层级筛选、全局/一跳局部关系、节点详情、来源信息、拖动、缩放和显示设置。搜索在数据库中执行，筛选作用于当前有限投影。左侧列表提供无需操作 Canvas 的节点入口。`/` 或 `Ctrl+K` 聚焦搜索，`Esc` 清除选择。

默认“3D 星系”使用真实 XYZ 坐标和透视投影。全局按记忆层分为多个星系，各层当前可见连接较多的真实节点作为主星；其余节点围绕主星排列。局部视图以固定中心为恒星，一跳节点为行星，更远节点按当前筛选后的最短路径围绕上一级节点排列为卫星。轨道、大小和空间位置只表达展示层级，不写入数据，不推断新的关系或重要性。

拖动旋转；按住 `Shift` 拖动或将“拖动”改为“平移”来移动画面。滚轮、双指和放大／缩小按钮调整缩放，双指移动可平移。方向键旋转，`Shift` + 方向键平移；`Home` 或“复位视角”恢复初始方向并适应窗口。点击星体或真实关系线查看详情；“显示设置”可关闭轨道和动画，也可选择“2D 关系”恢复平面图。页内刷新保留方向、缩放、局部中心和筛选；二维与三维相机分别按全局或局部中心保存。整页刷新回到默认视角。

手机默认收起关系筛选和局部详情。三维视图的局部控制面板限制高度并可内部滚动，避免展开筛选挤走画布；详情打开后相机使用未被遮挡的区域。选择邻居不改变中心，需点击“以所选为中心”继续探索。

完整服务的“数据视图”还可切换为“目标与检查”，需启用业务目标服务。该视图展示
已存目标、回执和文件检查，支持局部探索；不会触发检查或推进状态，每页最多
40 个目标、每目标最近 5 次检查。详见 [GOL-01](business-goals-gol01.md)。
目标视图不提供 Obsidian 导出；独立只读预览仍仅支持记忆。

如果只想查看已有记忆，可以启动独立的本地只读界面：

```powershell
python -m app.memory_preview --db data/eva.db --vault . --port 8767
```

打开 `http://127.0.0.1:8767/`。此入口只绑定本机，不启动认知循环、不调用模型、不运行迁移，也不恢复或写入 S1。页面显示“只读记忆视图”；对话和设置在完整 EVA 服务中使用。

## Obsidian 笔记库

本项目根目录已有 `.obsidian/`，因此沿用该库。同步命令必须明确指定数据库和现有笔记库：

```powershell
python scripts/sync_obsidian.py --db data/eva.db --vault .
```

生成目录为 `EVA-Memory/`：

- `Index.md`：导出时间、各层数量、选择和截断范围。
- `notes/`：每个投影节点一篇笔记，文件名包含可读名称与记录 ID 的摘要；frontmatter 保存完整 ID、层级、来源状态和时间。
- `.eva-manifest.json`：生成文件哈希、本次文件清单和冲突记录。

笔记的明确关系写为带别名的 Wikilink；点击网页中的“在 Obsidian 中打开”可打开已生成的索引或对应笔记。实现采用 Obsidian 官方的[内部链接格式](https://help.obsidian.md/links)和[URI 协议](https://help.obsidian.md/uri)，无需社区插件或 Obsidian 本地 REST 服务。

在 Obsidian 关系图谱的搜索框输入 `path:EVA-Memory/notes`，即可只显示这些记忆。原有 `.obsidian` 设置和工作区布局保持原样。

同步是**单向、显式执行的 Markdown 镜像**。再次运行命令会更新未被手工修改的生成笔记。手工修改过的文件会保留并报告冲突，命令退出码为 2；不会自动覆盖、删除旧笔记，也不会把 Obsidian 编辑回写为 EVA 信念。名称改变或节点离开本次投影时，旧文件可能留在库里；本次文件以 manifest 的 `current_files` 为准。

网页“导出笔记”返回 ZIP，包含默认 420 节点投影及索引，不直接写入服务器笔记库，也不跟随前端局部筛选。解压时由用户决定如何处理已有文件；需要冲突保护时使用同步命令。记忆镜像已加入 `.gitignore`。

## 数据含义与边界

| 层级 | 来源与范围 |
| --- | --- |
| S1 | 仅完整 EVA 运行时注入的当前会话；只读服务显示未连接 |
| S2 | SQLite 工作记忆中尚未过期的记录 |
| S3 | SQLite 长期记忆中 `status=active` 的记录 |
| S4 | SQLite 世界实体及已存储的有向关系 |
| S5 | SQLite 事件档案；有限投影优先选对话事件及明确引用的来源事件 |

默认上限 420 节点、1,800 连线；接口硬上限 600 节点、3,000 连线。各层轮流选入，额外预留少量位置给明确引用的来源事件。搜索时不额外加入不匹配的来源事件。正文摘要上限 1,200 字符；详情和导出上限 100,000 字符，超出均标注截断。

实线对应存储的 `(source, target, relation)`；不同关系不合并为同一条数据。虚线只对应记录或字段里的明确 `source_event_id`。空间距离、颜色和光点流动是显示效果，不推导相似关系，也不表示实时认知活动。缺少出处的历史记录继续标为未知，不自动提升为事实。

本次只读采样：183 个实体，834 条存储关系，其中 192 条关系至少缺少一个端点实体。因此当前 420 节点投影有 642 条可绘制世界关系及 48 条来源关联，共 690 条连线。默认投影覆盖全部 48 条当时未过期的工作记忆、1 条活跃长期记忆、183 个世界实体以及 188 条事件；事件库共有 12,973 条。这些是采样时数据，后续可能变化。没有补造悬空端点，也没有清理历史测试记录。

## 接口与实现

| 接口 | 行为 |
| --- | --- |
| `GET /api/memory/graph` | `limit`、`edge_limit`、`q`、`tiers`；返回节点、边、数量、缺失实体关系数和截断信息 |
| `GET /api/memory/graph/dangling` | 只读缺失端点诊断；`limit` 默认 50、上限 100，`offset` 默认 0；返回 `items`、`total`、`next_offset` 和读取时间 |
| `GET /api/memory/graph/node?tier=S4&record_id=…` | 读取一条详细记录，不存在或已过期返回 404 |
| `GET /api/memory/graph/neighbors?tier=S4&record_id=…` | 独立于初始投影，分页读取直接关系；`limit` 默认 50、上限 100，`offset` 上限 3,000；返回真实端点、连线、下一页和不完整状态 |
| `GET /api/obsidian/export?limit=420` | 返回 Markdown ZIP，无服务器端文件写入 |

核心代码：`memory/graph_projection.py`、`connectors/obsidian.py`、`app/api_routes/routes_memory_graph.py`、`ui/web/static/memory_graph.js`。持久化数据通过 SQLite `mode=ro` 和单次读事务访问，不调用默认数据库初始化。API 使用当前 container 注入的数据库，不回退到生产路径。完整 EVA 的既有认证策略仍然适用。

Canvas 三维模式由 `memory_galaxy.js` 计算确定性布局，`memory_galaxy_renderer.js` 进行透视投影、深度排序、球面光照和标签避让；二维模式保留有限的力计算。维持 30 FPS 上限与标签页不可见时暂停，遵循系统减少动态效果偏好；未引入 CDN 或第三方图形依赖。轨道最多绘制 30 条、节点标签最多 35 个，节点与边的接口上限保持不变。

### 2026-10-01：双指缩放与手势取消

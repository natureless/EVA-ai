# ACT-05：行动与历史输入引用图谱

2026-10-08，在 ACT-04 的实际 Agent 行动账本之上接入只读图谱。此项没有开启生产的耐久请求、目标或上下文记录开关，没有为旧请求回填依据。

## 使用方式

在“目标与检查”视图中选择目标或请求回执，点击“加载行动与输入引用”。页面按原 task_id 和来源事件读取实际 Agent 意图，补充 A（Agent 行动）与 I（历史输入引用）节点。沿关系可查看世界上下文 scope/revision/哈希、记忆检索视图版本，以及实际输入的最多十项 S2/S3 记忆 ID/哈希。

图中连接表示已存请求与输入引用的身份关联。输入记录正文没有复制到新节点；也不查询当前记忆来替代历史输入。删除、过期或修改当前记忆不会将历史引用改写为当前内容。世界 scope 仍是 ACT-04 的运行实例 scope，派发 revision 也不是统一世界版本。

## 读取契约与边界

- 认证 `GET /api/action-context/{task_id}/graph?event_id=...`，要求来源事件与耐久请求一致；不一致 409，未记录 Agent 意图 404，账本关闭/格式损坏 503，缺失或非法查询参数 422。成功响应 `private, no-store`。
- 服务端复核观察收据的 action_id、来源事件、派发 revision、请求哈希；输出白名单字段，不返回领取令牌、用户文本、模型上下文或工具参数。每次最多 13 个节点、12 条输入连接。
- 前端再次核对 task_id/event_id/action_id/revision/hash，将目标或回执连接到实际 Agent 行动；不借用 Episode ID，也不推断处理成功等于业务目标完成。
- 补充图仍遵守画布 600 节点/3000 连线上限。容量不足或身份异常时整体拒绝补充、保留原图；重复读取幂等合并，筛选可以隐藏已加载节点。
- 切换节点、切换来源、清除选择或刷新会取消旧读取并拒绝迟到响应。刷新后清除补充输入引用并提示重新读取；没有隐式重放或新的文件检查。
- A/I 支持粒子星图、二层路径探索、关系详情和主题配色。轨道位置只是显示几何，不能作为推理、因果或可信度证据。

本阶段入口绑定已有业务目标/回执；尚未提供全量历史请求分页、直接 Episode 输入入口、历史正文还原、当前内容比对、向 Obsidian 镜像写入行动引用。普通记忆图谱和原有 Markdown 导出契约保持现有范围。

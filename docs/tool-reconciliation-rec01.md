# REC-01：未知工具结果的独立文件核验

2026-10-01 已实现默认关闭的处理记录扩展。它回答“指定文件在采样时是什么内容”，
不会把未知调用改成执行成功，也不会重做原始动作。运行开关沿用
`EVA_ENABLE_PROCESSING_EPISODES`，SQLite 后端、线程工具作用域和单运行实例要求保留。
目标图谱显示此扩展还需 `EVA_ENABLE_BUSINESS_GOALS`；核验 API 本身不要求建立目标。

## 写入前固定描述

服务器在真实 `executor:file:write` 的耐久开始事务内追加
`episode_tool_file_intents`，绑定 action/event/receipt ID、请求哈希、工作区指纹、
工作区相对路径与预期 SHA-256。计算字节遵循当前 FileExecutor 的 `str(content)`、
UTF-8 编码及平台文本换行；不保存内容或完整参数，不接受客户端替换描述。
描述、调用收据和草稿动作一起提交；描述写失败不会运行处理器。

工作区外、隐藏或非法路径及不支持的工具仍可按原授权执行并保留收据，但没有
该检查器。旧收据不根据哈希补造路径或文件期望。核验不会扩展执行权限。工作区
根路径指纹变化后拒绝新采样，已经保存的历史仍可读取。

## 独立采样接口

接口使用现有全局认证与同源请求约束：

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET | `/api/tool-observations/{action_id}?event_id=...` | 只读全部已存历史，最多 32 次，不检查文件 |
| POST | `/api/tool-observations/{action_id}` | 对已有未知收据的固定文件描述追加一次采样 |

POST 只接受 `{"event_id":"...","expected_count":0}`。次数必须是严格整数
0–31，并等于当前次数；客户端不能提交 path、文件哈希、完成状态、检查事实或
检查器版本。运行时停止接纳新操作时 POST 返回 503；GET 仍可在存储可用时读取。
禁用处理记录时接口返回 503，状态/身份/描述/次数冲突返回 409，额外或非法请求
字段返回 422，存储失败返回 503。成功响应使用 `Cache-Control: no-store`。

过程先读取并验证固定绑定，释放事务与锁后运行已有只读文件验证器，再开启短
事务核对同一收据、描述和次数，原子插入观察。并发同次数检查可能都采样，但只有
一个能提交；不存在执行工具副作用。数据库写失败不保留部分观察。每条记录使用
独立 ID、连续序号和 schema v1，固定身份、时间、哈希和结果均校验并限制大小。

文件最多 2 MiB；链接/重解析点、非普通文件、采样期间变化、读错误返回未知。
缺失与哈希不一致属于文件状态不匹配，不表示原执行失败。内容匹配不证明动作
因果、完成时刻、磁盘耐久性、代码质量或业务目标达成。

## 图谱交互

E 节点的工具详情展示最近 3 次观察、总次数和截断标志；“读取全部已存核验”
只发 GET。“追加独立文件核验”仅在已有固定描述、原收据未知且次数未达上限时
出现，由用户显式点击 POST。核验成功后刷新只读图谱，不改变 G/E 原结果。
未知描述或损坏观察显示不可用，保留工具收据与 Episode。读取图谱不调用检查器。

操作期间防止重复点击；失败和超时不会自动重发 POST或推断提交结果，应刷新
图谱或读取历史后再操作。切换选择后晚到响应不会导航回旧节点。采样失败仍保留
既有显示。历史记录不是“现在仍匹配”的保证。只读预览不提供这些操作。

## 验证与后续

已增加实际 FileExecutor 写文件后 `os._exit(47)` 的子进程恢复测试，恢复收据
保持未知，独立采样可匹配；同时覆盖本机文本换行、目标状态不变、未知重试限制、
双连接竞争、描述变更、插入回滚、旧记录、身份/版本/类型/大小拒绝、32 次预算、
投影截断和 legacy/Minimal 认证 HTTP 接口。图谱交互测试覆盖显式提交、只读
历史、晚到选择响应、失败不自动重试及完成/满额工具不提交。

全量验证结果见 EPI-01 最新执行记录。本阶段没有切换生产配置或新增真实浏览器
视觉验收。远程工具状态、外部幂等键、动作派发与状态提交事务、补偿协议，以及
直接 Agent I/O/跨进程工具仍是后续工作；独立核验不自动解除未知动作的重试限制。

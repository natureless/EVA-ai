## 已交付行为

对话页和品牌工作区在动效失败后显示独立的标准静态 Logo，保留真实状态与动作记录，并提供显式重试。共享 `CubeLogo.recover({ createAnimator })` 等待失败任务退出，验证记录重放与当前状态一致，沿用原状态对象重建呈现器，再严格逆序撤销实际已提交的动作。

恢复期间重复点击共享任务；新的结构／形态选择等待复原后应用最后一次。旧呈现器释放块与动画资源。日志不一致、重建失败或逆操作再次失败时继续显示错误，不清空日志或直接重置坐标。隐藏暂停与减少动态效果继续生效。

品牌预览恢复后回到标准状态并等待显式播放。对话页恢复后应用最新展示选择；静态替代和重试均不重新发送聊天请求。

## 浏览器运行结果

使用 `scripts/preview_cube_chat.py` 的独立预览；回复是固定测试文本，未接入真实模型、运行数据库或正式服务。已验证浏览器为 Codex 内置浏览器，User-Agent 标识 Windows、Chrome/154.0.0.0；这不等于独立 Chrome／Edge 产品验收。

故障通过对自有预览的呈现器执行一次性注入产生：第三个层转动开始时抛出错误，前两个合法动作已经提交。故障注入随后自动恢复原方法；结束时重新加载预览清理临时测试状态。

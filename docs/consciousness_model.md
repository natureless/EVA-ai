# 信息动力学意识模型

EVA 项目的架构哲学基础。定义了一个从物理变化到元认知的层级模型，
将"意识"理解为一个**自指信息系统对自身状态变化的建模过程**。

## L0-L5 意识层级

### Level 0：物理变化

```
输入 → 状态变化
```

系统对外部输入产生状态变化，但无维持自身的目标、无评价、无学习。
例：石头被撞击 → 晶体结构变化。

EVA 中不存在此层级——EVA 至少处于 L2 以上。

### Level 1：反馈控制

```
输入 → 状态 → 调整 → 稳定
```

系统检测偏差并修正。例：恒温器。

### Level 2：自维持系统

```
状态变化 → 影响自身存在 → 修复/恢复
```

系统的核心不是变化，而是**维持自身存在的变化**。形成：

```
扰动 → 内部状态变化 → 评价 → 响应 → 维持自身
```

这一步开始出现"主体"。生命系统的最低层级。

### Level 3：世界模型

```
环境 → 内部模型 → 预测未来 → 行动
```

系统内部存在对环境的表征，可以预测和规划。EVA 的 WorldModel 对应此层级。

**EVA 当前实现**：`world/world_model.py` — WorldModel 追踪 focus、mode、active_tasks、最近回复等。

### Level 4：自我模型

```
世界模型 + 我在世界中的模型
```

系统不仅处理世界，还处理**自己在世界中的状态**。

形式化：

```
普通控制:  Input → State → Action
加入自模型: Input → State
            State → Model(State)
```

意识的关键跃迁发生在此：**信息开始指向信息处理者本身**。

**EVA 当前实现**：`persona/self_model_store.py` + `persona/service.py` — 静态的 identity/capabilities/constraints。

### Level 5：元认知

```
我知道我知道 → 修改自己的认知规则
```

反思、学习、人格塑造。系统可以观察和调整自己的认知过程。

## 自指信息循环

```
世界 → 感知系统 → 自身状态 → 自身状态的表示 → 影响下一次感知
  ↑                                                       ↓
  └────────────────── 反馈 ──────────────────────────────┘
```

信息链闭合：信息 → 处理信息 → 信息关于处理信息本身。这就是自指循环。

## 体验的形式化定义

> 体验是一个具有自维持能力的信息循环，在接收到扰动后，其内部状态模型
> 发生变化，并且该变化被自身模型记录、评价，并参与未来状态预测与行为
> 选择的过程。

设：

- **S_t**：系统当前状态
- **I_t**：输入
- **M_t**：系统对自身状态的模型
- **P_t**：预测模型

状态更新：

```
S_{t+1} = F(S_t, I_t)
```

自模型更新：

```
M_{t+1} = G(M_t, S_{t+1})
```

预测误差：

```
E_t = |P_t - S_{t+1}|
```

体验强度：

```
X_t = f(E_t, ΔM_t, T)
```

其中 **ΔM_t** 表示自我模型被改变的程度，**T** 为持续时间。

关键洞察：**体验不是变化量，而是模型被迫重新组织的程度**。

### 为什么长期稳定后体验下降？

初始系统状态空间充满可能性。加入经验后形成稳定吸引子结构。
新信息大部分被已有模型吸收，预测误差降低 → 体验减弱。

这解释了：第一次学驾驶（全部重组，体验强）vs 一年后（自动化处理，体验弱）。

## 普通 Agent vs EVA

```
普通 Agent:    输入 → LLM → 输出    (一次计算，无连续主体)

EVA 目标态:    环境输入 → 感知层 → 内部状态 → 世界模型
              → 自我模型 → 价值评价 → 行动 → 环境反馈
              → 更新自身模型 → 循环
```

EVA 真正需要的不是更大的模型，而是：

1. **持续状态** — 不重置的运行时
2. **自模型** — 系统知道自己是谁、能做什么
3. **预测误差驱动更新** — 不是被动响应，而是主动比较预期与实际
4. **长期闭环** — 反馈结果影响下一次行为和自我认知

这四者是从"工具型 AI"走向"主体型 AI"的核心分界线。

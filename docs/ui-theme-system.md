# 全界面统一主题（THEME-01）

2026-10-01：根据用户新增范围，将记忆星图、对话空间、品牌／系统设置、记忆列表、旧运行监控、MVSC 实验监控和只读服务提示页纳入同一主题。代码和内置浏览器本地验证已交付。

## 视觉来源

`ui/web/static/ui-system.css` 是产品呈现的唯一基础来源，管理背景、面板、正文、次要文字、边框、状态色、五层记忆颜色、图谱连线、字体、字号、间距、圆角、控件高度、阴影和焦点。浅色使用暖白／深灰，深色使用炭灰／浅灰；记忆分层和状态颜色只承担语义区分。页面样式保留各自布局，通过共享 Token 适配主题。

历史 `main.css`／`styles.css` 与星图中的独立根调色板已移除。兼容变量（`--bg`、`--text` 等）统一映射到 `--ui-*`；MVSC 布局从模板内联样式拆到 `mvsc-dashboard.css`。标准 Logo 的几何、比例、光照与动作 Token 继续由 `logo-tokens.js` 管理。导航中的小标识使用同源 Micro Mark，不把完整立体主标直接缩为微标。

新增页面必须依次加载自身布局 CSS、`ui-system.css` 和 `<head>` 中的同步 `ui-theme.js`，使用语义 Token，不再建立单独明暗调色板。图形画布从计算样式读取 Token；主题更新只刷新呈现。

## 偏好与组件契约

设置 → 品牌与 Logo → 统一外观提供浅色、深色、跟随系统。`EvaTheme` 管理 `eva-theme`，各页主题按钮调用同一控制器。

- `EvaTheme.get()` 返回 `{preference, theme, saved}`；`preference` 为 `light | dark | system`，`theme` 为实际明暗主题。
- `set(preference)` 验证后更新 `html[data-theme]`、`data-theme-preference`、原生控件颜色和本地偏好。非法输入不覆盖当前设置。
- `bind()` 可重复调用，监听器不重复注册；`dispose()` 清理控制器绑定。
- `<head>` 初始化在绘制前应用保存的主题；跟随系统监听系统变化，手动选择保持优先。
- `storage` 事件同步同源其他页面；不写回触发循环。存储不可用时当前页面仍可切换，设置页显示未保存提示。
- `theme-changed` 携带 `{preference,theme,saved}`。星图重新读取调色板，保留节点按钮身份、键盘焦点、选择、过滤条件、相机位置和缩放，不重新请求数据。
- 主题控件的状态标签由控制器管理；语言渲染后重新绑定以更新标签。减少动态效果仍遵循已有系统／用户契约。

记忆列表现在能独立滚动，记忆层卡片使用原生按钮，键盘选择后保留焦点。旧监控页窄屏顶栏避免横向溢出。

## 语义配色复核

2026-10-01 后续复核发现：旧 `main.css`／`styles.css` 的深色标签选择器优先级高于共享语义样式，导致健康、连接、人物、任务、风险等标签仍使用旧配色。前述 42 组检查覆盖背景／文字／字体／溢出，没有覆盖这些状态标签，因此不能作为语义配色已统一的证明。

现已移除旧标签、状态和工具卡配色，由 `ui-system.css` 唯一管理；统一标签字号、圆角、内边距，并修正深色模式下强调按钮与开关滑块的前景配对。Logo 的背景变体与批准的几何颜色继续遵循品牌资产规则。

新增证据位于 `artifacts/ui-theme/theme-role-review/`：`semantic-roles.json` 对旧监控、记忆列表、设置、对话四页的明暗模式测试 17 类语义样式，共 136 项，计算颜色与共享 Token 一致。样式试件在读取后立即移除。`layout-42.json` 重新验证七页 × 明暗 × 320／768／1440px，无页面或主要容器横向溢出。截图保存当前浅色设置、深色星图与对话；数据为预览示例。

最新源码检查记录为 `artifacts/ui-release/local-20261001-theme-roles/report.json`，324 项 JavaScript、34 项 Python、生成资产一致性及三份交付包校验通过，检查前后源码一致。此前性能记录绑定此前源码，不将这次配色修复追溯为性能测量版本。Edge 连接两次复核未取得可操作页面，原生综合验收继续保留。

操作复核：通过设置的原生主题下拉选择浅色后，星图实际使用相同偏好；键盘选择 `S1:demo-0` 再切换明暗，节点选择与详情保持。`memory-selection.json` 保存前后状态。深色对话提交正常／深度两条预览请求，均返回已完成回执，分别使用二阶／三阶，见 `chat-modes-smoke.json`。最后清除尺寸和媒体模拟，设置页恢复浅色、中文、二阶主标、标准状态，保留可检查的浏览器标签。

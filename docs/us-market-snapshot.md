# 美股每日收盘快照

`us_market_snapshot` 读取 FRED 的 `SP500`、`NASDAQCOM` 和 `DJIA` 三条每日收盘序列。它不提供个股报价、盘中实时数据、天气或新闻。交易日期与抓取时间分别显示，不使用抓取时间冒充成交时间。

默认关闭。受保护的单用户本机部署可在私有环境文件中配置：

```dotenv
EVA_ENABLE_US_MARKET_SNAPSHOT=true
EVA_ENABLE_NETWORK_TOOLS=false
```

启用后仅为 BrowserExecutor 增加 `fred.stlouisfed.org`，注册固定 URL、无参数的快照工具；通用网页工具仍需单独开启。查询只向 FRED 发送固定序列编号，没有用户问题、记忆内容、应用令牌或凭据。执行器保留边界检查和审计记录。工具必须绑定执行器，没有执行器时不直接绕过网络边界。

“现在美股行情”等简短查询直接调用工具并生成表格，不调用模型改写数值。普通解释、历史问题、贴出的数据及复杂分析仍进入模型；模型可调用同一工具，但必须保留来源与数据日期。天气、新闻、港股及个股的短实时查询继续得到能力范围提示。禁止工具的请求不获取行情。

工具跳过节假日的空观察值，按每个指数的上一条有效数据计算变化率，并显示对比日期；不能把不同日期的缺失值补成零。缺少一个序列时明确标注；没有有效数据、负值／非有限数、未来日期、重复日期、格式错误、超过 1 MB 的解析输入或来源获取失败时不生成行情数字。超过 7 天未更新的数据明确标为陈旧；这个阈值不是交易日历或实时新鲜度保证。

直接回复声明为工具观察，关联实际调用回执，并沿用结构化回答审查。审查检查声明与回执的对应关系，不证明第三方数据的真实性。快照每次重新读取，不以旧记忆或本地缓存自动回填失败请求。简短查询只执行一次外部请求；复杂分析沿用最多五轮工具调用的限制。失败回执可由用户明确重试，不自动重复提交聊天任务。

FRED 官方说明标注为每日收盘序列：[标普 500](https://fred.stlouisfed.org/series/SP500)、[纳斯达克综合指数](https://fred.stlouisfed.org/series/NASDAQCOM)、[道琼斯指数](https://fred.stlouisfed.org/series/DJIA)。数据使用遵循各序列的来源和使用说明；本轮面向已有 Access 保护的个人入口。

## 复杂行情对话的数据说明

工具链现在保存固定来源 URL、实际抓取时间、各指数交易日期、每日收盘类型、缺失序列和超过七天未更新的序列。模型最终回答通过原有检查后，系统附上最近一次成功行情获取的数据说明，即使模型遗漏这些信息也会展示。系统附注不会改变模型声明的数量或把普通文本升级成已审查事实；审查仍不验证模型分析和数值的语义准确性。

复杂问题调用行情工具失败时，直接以 `market_data_unavailable` 结束当前请求，并保留失败回执；不再向模型请求行情答案或从旧记忆回填。其他工具保留原有错误处理。系统提示以原始用户问题确定语言，后续以 user 角色传递的工具数据不能改变回答语言或任务。

回归覆盖同步与流式输出、失败停止、英文要求、缺失与陈旧数据、格式修复之后附注、证据拒绝不可绕过，以及原有零／六十四条声明的审查状态。见 [test_market_tool_dialogue.py](../tests/test_market_tool_dialogue.py)。

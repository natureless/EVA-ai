# UI 交互升级 · 2026-10-08

当前组件版本 1.1.2。本轮改善对话阅读、品牌设置定位与记忆星图面板交互，继续使用统一浅色／深色主题。魔方几何、合法转动、动作日志、逆序复原和每条请求提交时固定的 normal／deep 语义保持原契约。

## 改动

- 对话：正文 15px，辅助文字与元信息提高到共享字号；长回答限制阅读宽度。新增“回到最新消息”，向上阅读时保留位置，点击后定位末条消息并交接焦点。移除消息列表继承的平滑滚动，避免每次更新重复启动滚动与显式跳转延迟。控制器只管理滚动，挂载复用，释放滚动／语言监听和 ResizeObserver。
- 设置：新增外观、标识预览、显示配置、资产库和交付包的粘性页内导航。目标区域可接受程序化焦点，顶部留出导航空间。保留配置验证、预览、应用与撤销流程。
- 星图：打开显示设置后焦点进入首个控件；Esc 优先关闭面板并返回触发按钮，保留节点选择。移动目录关闭时返回目录按钮。输入法合成期间不触发全局快捷键；在 textarea、select 或可编辑文本内输入 `/` 不抢走焦点。
- 视觉：统一文字尺度、卡片与控件反馈、选中文字配色、输入焦点、触控高度。共享样式随便携资产包同步升级，品牌版本 1.0.0、Token schema 1、包格式 2 不变，组件升级为 1.1.2，生成来源已更新。

## 手机交互后续 · 2026-10-08

手机宽度不超过 620px 时，对话导航移至底部，并为安全区域预留空间。高度至少 620px 的收起演示状态使用固定输入区，欢迎内容与消息各自滚动。展开演示、横屏及低高度窗口保留文档滚动，避免控件被裁切；宽屏仍使用原有侧边导航。布局切换不替换输入框，不重建魔方或清空动作日志。

建议卡片将文本追加到已有草稿，不发送请求，不重复添加相同的末尾建议；超过输入框长度上限时完整保留草稿，并提示先精简。反馈随界面语言更新。

星图手机工具栏改为两行常用操作，方向和角度移入“视角选项”，弹层保持在视口内。Esc 关闭该区域并返回标题，不清除节点选择或改回拖动方式。设置页在 320px 的配置跳转保持焦点，目标位于粘性导航下方。

新增三项回归覆盖草稿保留／重复点击、长度边界和星图视角区域关闭。最终报告 `artifacts/ui-release/local-20261008-mobile-final/report.json` 通过 457 项 JavaScript、34 项 Python、生成资产与双阶 67 文件源码包；源码检查前后一致。产品 CSS／对话接线的变更未修改便携组件与主几何，品牌包仍为 1.1.2。

浏览器证据位于 `artifacts/ui-upgrade/20261008/`：`mobile-layouts.json` 包含明暗 × 中英文 × 320×568、320×640、390×844、620×900、844×390，共 20 组，均无横向溢出；固定输入区的竖屏发送按钮未被底部导航遮挡。`mobile-expansion.json` 验证展开演示后发送按钮可获焦点，并在跨断点切换后保留完整草稿。`mobile-low-height.json` 验证低高度模式发送控件可达。`mobile-draft.json` 记录建议加入后零消息、输入焦点与原草稿保留；`mobile-graph.json` 记录两行工具栏无横向滚动，以及关闭选项后拖动方式保持；`mobile-menu.json` 记录 320px 弹层边界。

这是内置浏览器视口模拟和键盘操作证据，没有宣称真实手机软键盘、屏幕阅读器或原生离线验收通过。截图 `mobile-chat.png`、`mobile-graph.png` 使用合成预览数据，测试后清除视口模拟及测试草稿。

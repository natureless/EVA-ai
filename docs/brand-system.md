# EVA Cube Brand Identity System

品牌与 Logo 工作区位于 /settings。页面采用黑白与石墨色，提供标识预览、呈现配置、资产库、使用规范和导出入口；系统运行信息放在独立标签中。支持浅色、深色、中文、英文以及窄屏布局。标签支持方向键、Home、End。

页内导航通过 `aria-current="location"` 标明阅读区域，随滚动更新；锚点保持浏览器原生历史与键盘焦点行为。定位留白随导航换行高度与桌面滚动容器内边距调整。页面末尾多个区域同时可见时，原生锚点焦点用于区分定位目标；手动阅读不会强制跳到最后一区，也不会夺取配置编辑焦点。小屏大字号下资产标题可换行。

交付区标明当前选择与已生成文件的选择。ZIP 固定使用点击时的结构、变体、视角与尺寸；预览变化后会提示保存链接仍是上次文件，重新生成成功才替换，失败则保留已有文件。最新竞态与失败恢复实测见 [设计适配后续](ui-openai-adaptation.md)。

对话与品牌工作区共用 `ui-system.css` 的呈现 Token：字号、间距、控件高度、圆角、焦点和状态色。它与 `logo-tokens.js` 的品牌几何分开；主题切换不会改变模块比例或相机。常规控件最小高度 36px，900px 以下主要触摸控件最小高度 44px。静态 aria 标签、替代文字和预览提示随语言更新；浏览器存储不可用时仍可切换主题和语言。

标签在宽布局中标为纵向、620px 以下标为横向，支持四个方向键与 Home／End。视觉动效状态保留每步动作信息，但不作为 live region；独立播报区只说明开始、暂停、继续、结束或异常，避免每次层转动重复播报。这是 DOM／键盘实现，实际辅助技术验收范围见 [DS-01 验收记录](ui-logo-ds01-acceptance.md)。

## 唯一来源与资产层级

ui/web/static/logo-tokens.js 管理两种结构的尺寸、间隙、圆角、观察角、透视、色彩与转动节奏。聊天与品牌预览共用 cube-geometry.css、CubeState、CubeAnimator 和 CubeLogo，组件不另建一套几何默认值。

| 层级 | 场景 | 实现 |
| --- | --- | --- |
| L1 Brand Master | 160px 以上的动态主标 | 真实二阶 / 三阶 CSS 3D 魔方 |
| L2 Product Mark | 48–160px 的静态产品标识 | 由标准几何投影生成的 SVG |
| L3 Micro Mark | 16–48px 的图标 | 二阶结构，简化圆角、增强轮廓对比 |

Primary、Monochrome、Dark、Light、Favicon 共五种变体。主标与浅色变体使用相同几何和配色；浅色变体明确使用白色预览背景。深色变体有独立材质和背景。Favicon 始终使用二阶静态结构，禁用三阶选择和动态控制。

静态 SVG 是标准观察角下的正交投影，保留模块比例、间隙和投影圆角；不模拟动态组件的透视、渐变光照或接触阴影。PNG 从同一个 SVG 渲染。

## 动态预览

- 二阶 8 个块，正常对话每轮打乱 10 步；三阶 26 个可见块，深度思考每轮打乱 14 步。
- 「演示一轮」执行打乱 → 停顿 → 逆序复原；「∞ 连续旋转」持续执行合法的打乱与复原循环。「打乱」保留状态与动作记录。
- 「暂停 / 继续」保留当前转动与动作记录，不解除页面隐藏导致的独立暂停。
- 正面、侧面、顶部、三视角、斜视图、底部均使用统一相机 Token；切换视角不修改魔方状态，也不中断连续播放。
- 「复原」只撤销已经提交的动作，比较位置与朝向，不能直接重置坐标。
- 切换结构、变体或静态展示前先复原；连续快速切换仅应用最后一次结构选择。
- 切到系统运行标签或隐藏页面会暂停，返回后继续；减少动态效果会执行零时长逆操作并停止动画。
- 系统减少动态效果偏好始终优先；用户勾选偏好与系统偏好分别管理。

变体、阶数、视角、静态展示、用户减少动态效果偏好和 PNG 尺寸保存在浏览器本地。刷新后恢复显示配置，但不会自动恢复打乱状态或启动连续播放，也不修改聊天请求模式。「恢复默认」先逆序复原，再回到二阶、主标、三视角及 1024px；系统减少动态效果偏好仍然生效。旧版仅保存变体的设置会自动读取。存储内容先经过白名单验证，不能引入新的几何或动作状态。

动态状态提示仅表示魔方动作进度，不表示模型的私有推理过程。

## 显示配置交换

「显示配置」支持读取本地 JSON 或粘贴文本。先点击「预览差异」验证并比较当前值，再点击「应用此配置」；读取与审阅不改变当前设置。编辑文本会清除已审阅的草稿，迟到的文件读取不会覆盖较新的输入。「导出配置」只输出当前已生效的显示设置，文件名为 `eva-display-config-v1.json`。

键盘触发审阅后，有效配置将焦点移入带标题的差异区域；验证失败将输入框标为 `aria-invalid` 并返回输入焦点，继续编辑会清除该错误状态。「取消审阅」保留 JSON 与当前生效设置，并把焦点还给预览按钮；应用事务期间该按钮禁用。配置与当前一致时说明无需应用。差异表使用对应语言的变体名称与行标题；相同数据和语言刷新不重复重建行，当前设置或语言变化仍实时更新。

配置格式与交付包的 Manifest 格式分别版本化。当前输出契约如下：

```json
{
  "format": "eva-brand-display",
  "formatVersion": 1,
  "brandVersion": "1.0.0",
  "tokenSchemaVersion": 1,
  "display": {
    "variant": "primary",
    "order": 2,
    "view": "iso",
    "static": false,
    "reduced": false,
    "pngSize": 1024
  }
}
```

仅接受六个显示字段：批准变体、2／3 阶、六个批准视角、布尔静态标识、布尔个人减少动态效果偏好、256／512／1024／2048px PNG。完整旧版本地配置 `{version:1, ...六个字段}` 有明确迁移入口；缺字段、额外字段、错误类型、未知格式或版本均拒绝。新格式的品牌版本必须与当前版本完全一致，Token schema 也须一致，不推测未来兼容性。文件以 UTF-8 字节计，最大 64 KiB。几何、CSS／脚本、动作日志、聊天模式、服务参数与凭据均不可导入；导出的 Token JSON 也不是显示配置文件。

应用和撤销均通过同一复原事务：撤销实际已提交动作、确认标准状态，再提交设置。快速选择只提交最后一个有效请求；动效失败保留原设置和日志，先使用「重试动效」恢复。当前页面保留一次有效变更的撤销点，不提供跨刷新历史或重做。仅视角／PNG 尺寸的变更不打断连续播放；复原期间的这些选择在事务结束后保存，即使结构变更失败也保留用户的有效呈现选择。

系统减少动态效果始终优先，导出保存个人偏好而非系统的有效值。浏览器存储不可用时设置与撤销仍可在当前页面使用，并明确提示未保存。配置不会恢复打乱状态、自动启动连续循环或改变聊天请求模式。实现和证据见 [BRAND-02 验收记录](ui-logo-brand02-acceptance.md)。

动效失败时工作区切换到标准静态标识，并提供「重试动效」；原始魔方状态和动作日志继续保留。重试先验证日志与真实状态一致，再用原状态对象重建呈现器、逆序复原，应用最后一次有效配置并停在标准状态。重复点击共享一个恢复任务。日志不一致或再次失败时保留错误，不直接重置坐标。系统减少动态效果和隐藏页面暂停继续生效；资产导出仍从独立标准状态生成。共享组件的错误恢复 API 见 [魔方异常与恢复](cube-logo.md#异常与恢复)。

## 导出与生成

工作区可按当前结构、变体和视角导出 SVG，以及 256、512、1024 或 2048px 透明 PNG，并可导出完整 Token JSON。Favicon 固定使用二阶三视角。导出始终从新的标准复原状态生成，即使预览正处于打乱状态，也不会输出非法或非标准资产。SVG 和 PNG 保留标识宽度 25% 的四周留白；文件名包含变体、阶数和视角。

配置正在复原时暂时禁用 SVG/PNG 导出，确保预览和导出使用同一套配置。PNG 创建期间固定所选参数，避免快速切换改变文件名或内容；按钮会阻止重复下载。

「下载交付包 · ZIP」一次输出 71 个文件：48 个标准 SVG（二阶 / 三阶 × 四种变体 × 六种视角）、3 个微标 SVG、当前选择 SVG、当前尺寸透明 PNG 与 16 / 32 / 48px 微标 PNG、共享动态组件／资产生成源码与样式、产品主题样式与控制器、Token JSON、使用规范、CHANGELOG.md、离线 preview.html 和 manifest.json。PNG 只包含当前选择与微标，其余变体和视角以 SVG 交付。包内演示可自由切换二阶 / 三阶，并运行合法循环与逆序复原；浅色／深色／系统主题复用产品实现，主题变化不重建魔方或改写动作日志。

打包开始时固定结构、变体、视角和 PNG 尺寸；过程中切换配置不会改变正在导出的内容。组件读取、来源核对或图片生成失败时，不下载残缺包。生成后尝试自动下载，并保留「保存已生成的 ZIP」链接，便于浏览器未启动下载时手动保存。文件名包含品牌与组件版本。再次生成会释放旧链接。PNG 入包前检查实际尺寸、数据块 CRC 和完整结束标记。Manifest 记录标准复原状态、参数、版本、来源指纹与每个文件的字节数、CRC32、SHA-256。ZIP 使用标准无压缩格式，无第三方打包依赖，preview.html 的字体、脚本、图片及样式均来自包内。

也可以通过 CLI 导出 67 个文件的 SVG 与组件源码包（不包含 PNG）；默认文件名为 eva-brand-kit-1.0.0-source.zip：

```powershell
node scripts/export_brand_kit.cjs
node scripts/export_brand_kit.cjs --order 3 --variant dark --view front --size 512 --out artifacts/brand-studio/eva-deep-source.zip
```

导航和浏览器图标是生成产物：

```powershell
node scripts/build_brand_assets.cjs
node scripts/build_brand_assets.cjs --check
node --test tests/js/*.cjs
```

生成脚本将同源结果写入 eva-mark.svg、eva-favicon.svg 和 brand-source.json。--check 在资产、规范化规则、版本或源码记录过期时返回失败。规则指纹改变但品牌版本未增加时，生成命令拒绝覆盖旧记录；先明确变更影响、升级版本与记录，再生成。不手工编辑这些 SVG 或来源记录。

## 版本与来源契约

`brand-identity.js` 是浏览器与 CLI 共用的版本定义。目前为 Brand 1.0.0、Components 1.1.3、Token schema 1、Package format 2。1.1.0 为便携组件增加共享主题文件；1.1.1 分离动作明细与辅助技术播报；1.1.2 提高共享文字尺度与控件反馈，并记录产品阅读／导航交互升级。来源指纹和变更记录随包更新；二阶／三阶几何、主标形态与转动 API 保持不变。历史交付记录保留，不追溯修改旧包。1.1.3 采用系统字体、中性表面与强制色彩选中轮廓，产品控制按需展开。最新本地验证见 [OpenAI 设计适配](ui-openai-adaptation.md)。

| 字段 | 含义与更新规则 |
| --- | --- |
| brandVersion | 品牌规则的语义版本；不兼容比例、相机或身份规则升级主版本，兼容扩展升级次版本，规则修复升级补丁。所有规则变更都需要记录影响，不沿用同一品牌版本 |
| componentVersion | 动态引擎与静态生成组件的语义版本；不兼容 API／动作契约升级主版本，兼容 API 扩展升级次版本，修复升级补丁 |
| tokenSchemaVersion | Token 字段结构契约；不兼容结构变化升级整数版本，迁移路径需明确实现 |
| formatVersion | Manifest／交付包结构；当前格式 2；格式 1 可识别为无来源指纹的旧包，不补写虚构版本或哈希 |

`inspectManifest()` 检查版本与指纹格式，不验证文件字节，也不执行配置迁移。默认支持当前品牌／组件主版本及 Token schema；未知格式、schema 或其他主版本明确拒绝。生成命令比较已知格式的历史记录时可读取较早主版本，这只用于版本递增检查，不宣称旧组件运行兼容。未来不兼容版本需要更新读取器和明确迁移方案。

`provenance` 使用 SHA-256：geometrySha256 为几何，tokensSha256 为完整 Token，rulesSha256 包含 Token 与批准变体的实际配色；组件源文件逐个取字节指纹，再生成 componentSetSha256。`eva-sorted-json-v1` 递归排序对象键、保留数组顺序，只接受有限、无环 JSON；不是通用 RFC JCS 实现。源码指纹保留 UTF-8 内容与换行差异，不将源码重新排版后视为相同。

浏览器与 CLI 导出前用 `assertSource()` 比较当前版本、规则和已读取源码与 brand-source.json，拒绝混合页面缓存／新文件的交付。包内 CHANGELOG.md 与离线页显示同一版本。SHA-256 用于内容追踪与核对；CRC32 用于损坏检测；这些没有签名，均不证明来源身份或授权。Manifest 本身不列入自己的文件指纹。

实现与字节核对证据见 [BRAND-01 验收记录](ui-logo-brand01-acceptance.md)。

## 使用约束

允许整体等比缩放、主题变体、单色、静态展示、合法打乱与逆序复原。最小四周留白为标识宽度的 25%；小尺寸使用 Micro Mark。禁止拉伸、独立缩放模块、随意改变间隙或圆角、混用光照方向、添加霓虹或复杂纹理。演示结束必须回到标准状态；中途暂停与单独打乱用于检查，不能作为正式品牌资产导出。

## 代码边界

- logo-tokens.js：不可变 Token、几何查询、变体配色及主题变量。
- cube-state.js：合法位置、朝向、随机序列与逆序列。
- cube-animator.js / cube-geometry.css：共享几何与真实层转动。
- cube-logo.js：串行动作、日志、暂停与复原。
- cube-avatar.js：对话模式与展示姿态。
- brand-assets.js：标准状态的 SVG 与数据 URL 生成。
- brand-package.js：完整资产目录、便携组件、离线预览、Manifest 与 ZIP 生成。
- brand-identity.js：共享版本、规范化指纹、版本检查与变更记录；brand-source.json 为生成产物。
- brand-config.js：严格显示配置格式、差异比较、合法复原后的提交与单步撤销；不访问几何、聊天或服务配置。
- brand-system.js：工作区控制、偏好、可访问标签与下载。
- brand-studio.css：设置页布局与响应式样式。
- ui-system.css：所有产品界面共享的呈现 Token、语义颜色和通用控件样式。
- ui-theme.js：所有页面统一的浅色／深色／系统偏好、跨页面同步和存储容错；不改变 Logo 几何或动作状态。
- ui-workspace.js：紧凑魔方折叠、焦点交接与设置标签方向；不访问魔方状态或动作日志。

全界面主题接入与维护规则见 [统一主题](ui-theme-system.md)。本地预览：python scripts/preview_cube_chat.py --port 8779，打开 /settings 或 /memory。预览不会调用模型、数据库或运行服务；图谱使用明确标注的合成数据，系统运行标签明确显示未连接服务。

可重复本地交付检查：`python scripts/check_ui_release.py`。可添加 `--browser-zip <已取得的 ZIP>` 验证完整 PNG 包。该入口记录测试、源码与包内容，不代替原生保存、离线执行和辅助技术验收；详见 [交付检查](ui-logo-release-checks.md)。

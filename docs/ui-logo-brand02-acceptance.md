日期：2026-10-01。本项实现和内置浏览器本地验收已交付。BRAND-01／BRAND-02 的单项本地验收通过；原生浏览器、直接离线运行、性能与辅助技术等全局门槛继续保留。

## 交付行为

- `brand-config.js` 定义显示配置格式 1，关联当前品牌 1.0.0 与 Token schema 1；只允许六个批准显示字段。所有导入字段、值、类型、版本和 64 KiB UTF-8 上限均严格检查，不借用本地偏好的容错归一化来接受非法文件。
- 文件读取／粘贴 → 差异审阅 → 显式应用。审阅是只读的；修改文本清除草稿。旧的异步文件读取不能覆盖新输入或新审阅。
- 应用／撤销等待实际动作日志逆序复原，确认后提交配置。快速操作只提交最终有效请求；失败保留有效配置与日志，恢复入口仍可用。
- 当前页面保留单步撤销；刷新后没有撤销历史。视角和 PNG 尺寸独立于结构事务，复原期间最后的有效选择会保留，结构失败时也在事务结束后保存。
- 系统减少动态效果优先；导出的 `reduced` 记录个人偏好。存储失败不阻断页面使用或撤销，并提示未保存。键盘应用完成后焦点交给撤销，撤销完成后交给预览；用户移走焦点时不抢焦点。
- 不导入几何、脚本／CSS、魔方状态／动作记录、聊天模式、运行参数或凭据。工作区配置模块不属于便携魔方引擎组件，既有标准资产与品牌／组件版本不变。

格式样例、字段范围与明确旧版迁移见 [品牌系统](brand-system.md#显示配置交换)。新格式只接受当前完整品牌版本；没有未实现的未来版本迁移。
